# my-spring-app

一句话说明项目用途。

## 技术栈
- Java 25
- Spring Boot 4.0（Maven）

## 快速开始
```bash
mvn spring-boot:run
```

## 命令
| 命令 | 说明 |
|---|---|
| `mvn spring-boot:run` | 启动服务 |
| `mvn test` | 运行测试 |
| `mvn package` | 打包 |

## 目录结构
```
src/main/java/com/example/app/
  Application.java     # 启动类
  HelloController.java # 示例接口
src/main/resources/
  application.yml      # 配置
```
